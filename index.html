Olá, eu sou a Amanda!

Sou desenvolvedora Full Stack Júnior, com foco no desenvolvimento de aplicações web, desde a construção de interfaces até a implementação de funcionalidades no back-end.

Tenho conhecimentos em HTML, CSS, JavaScript e React.js no Front-End, além de Node.js, Express e PostgreSQL no desenvolvimento back-end.

Gosto de desenvolver soluções completas, conectando interfaces, APIs e bancos de dados, sempre buscando organização, funcionalidade e qualidade de código.

Minha jornada

Minha evolução como desenvolvedora Full Stack

Uma jornada de aprendizado, prática e evolução constante no desenvolvimento de aplicações web completas.

01
Fundamentos

Fundamentos da programação

Comecei construindo minha base em lógica de programação e algoritmos, desenvolvendo o raciocínio necessário para resolver problemas através do código.

02
Desenvolvimento Web

Construção de interfaces web

Aprofundei meus conhecimentos em HTML e CSS, aprendendo a desenvolver interfaces estruturadas, responsivas e acessíveis.

03
JavaScript

Interatividade e lógica para aplicações web

Passei a utilizar JavaScript para desenvolver funcionalidades interativas, trabalhar com lógica de programação e consumir APIs em aplicações web.

04
Ecossistema Front-End

React.js e desenvolvimento de componentes

Avancei para o desenvolvimento de interfaces com React.js, utilizando componentes reutilizáveis, React Hooks e Styled Components para organizar e estilizar aplicações.

Projetos e prática

Transformando conhecimento em projetos

Venho aplicando meus conhecimentos em projetos próprios, colocando em prática conceitos de desenvolvimento web, responsividade, acessibilidade e organização de código.

Expandindo para o desenvolvimento Full Stack

Ampliei meus conhecimentos para o desenvolvimento back-end, utilizando Node.js e Express na criação de APIs e PostgreSQL para armazenamento e gerenciamento de dados. Apliquei esses conhecimentos no desenvolvimento do Boraê Delivery.
